# Chanakya-OS

"We have used AI for debugging purpose in our code and most specificially in browser app as we were facing problem with API fetching ,google was not getting embbeded in it."

Chankaya OS includes functional descktop environment on web, with applications like Notepad, Terminal, Weather app, Calculator, Browser, it has clock and shows current day also, and it has some customizable settings which you can apply for wallpaper. 

We built this whole Web OS entirely using HTML, CSS and JS. 

The goal was not just to design something visually appealing, but to simulate how an OS behaves inside a browser.
